# Tournamelon homepage

Static single-page homepage for pairing.tournamelon.com (English and Chinese, no external resources).
To preview, run `python3 -m http.server` in this folder and open http://localhost:8000.
It is intended for GitHub Pages; the `CNAME` file sets the custom domain pairing.tournamelon.com.
The download links point to https://github.com/tournamelon/thp-tools/releases (marked in index.html).
