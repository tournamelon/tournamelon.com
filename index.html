Tournamelon Arbiter

An offline-first desktop app for running chess tournaments, with two free command-line tools for checking and testing pairings.

Download PTC/RTG Read the status

Desktop builds: coming soon

Features

  • Dutch System, 2026 rules

    Individual Swiss tournaments under the FIDE Dutch System, with Baku acceleration.

  • FIDE 2026 tie-breaks

    Tie-breaks calculated under the FIDE 2026 rules (MTB26).

  • TRF-2026 import and export

    Read and write tournament files in the TRF-2026 format.

  • Continue from another program

    Continue a tournament from another program's TRF file, after an independent replay check.

  • Offline, bilingual

    Works offline. The interface is available in Chinese and English.

Free tools

PTC tournamelon-ptc

A pairings checker. It replays a TRF file and verifies pairings and standings.

tournamelon-ptc --help

RTG tournamelon-rtg

A random tournament generator for testing pairing engines.

tournamelon-rtg --help
